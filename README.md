# 碧蓝航线同人故事集

本仓库用于保存《碧蓝航线》同人短篇创作，与游戏官方无关。

## 文件结构

- `archive/`：编号001—147的历史分卷及上传说明，保留原始文件，不再拆分。
- `stories/`：从编号148开始，每篇故事单独保存为一个Markdown文件。

## 命名规则

新故事统一命名为：

`三位编号_故事标题.md`

例如：`148_好心眼的神明_Pro.md`

故事正文使用一级标题标明编号和标题，并保留 `*故事开始*`、`*故事结束*` 标记。
